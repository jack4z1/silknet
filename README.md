# 🌉 Silknet — Connect Browser AI to Local AI

**Silknet** bridges your local developer environment (VS Code, Cursor, Windsurf, terminal tools) directly to your active browser AI tabs (**ChatGPT**, **Claude**, and **Gemini**).

---

## 📁 Repository Structure

* **[`Silknet v1.0/`](./Silknet%20v1.0)** — The stable, tested release of Silknet v1.0:
  * Complete Chrome / Edge / Chromium browser extension (Manifest V3)
  * Local Node.js / TypeScript WebSocket bridge server
  * VS Code / Cursor Master Panel extension
  * Built-in Human Approval Permission Gate & Privacy Redaction Shield
  * Single-tab routing and multi-tab broadcasting
  * Ready-to-install packages in `Silknet v1.0/release/`

* **[`Silknet v1.1/`](./Silknet%20v1.1)** — The upcoming next-gen Silknet v1.1:
  * Dynamic multi-tab AI debate (ChatGPT + Claude + Gemini) with automated synthesis
  * File attachment pipeline (up to 20MB, up to 5 images/documents)
  * Voice prompting / Speech-to-Text
  * Enhanced browser extension popup with tab selectors and status indicators
