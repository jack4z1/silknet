# 🌉 Silknet for VS Code & Cursor

**Connect your code editor directly to active Browser AI tabs (ChatGPT, Claude, Gemini).**

Silknet gives you a zero-cost, privacy-first bridge to your frontier web AI accounts without paying for multiple API keys or risking rogue autonomous terminal calls.

---

## ✨ Features

- 🟢 **Live Browser Tab Detection:** Automatically detects open ChatGPT, Claude, and Gemini tabs in Chrome, Edge, and Brave.
- 🔒 **Human-in-the-Loop Approval Barrier:** Every query from terminal scripts or local AI requires your explicit permission before consulting the browser.
- 🛑 **Emergency Stop / Killswitch:** Instantly halt ongoing browser AI generation with one click.
- 🛡️ **Privacy & Redaction Shield:** Automatically scrubs local Windows/Unix paths, usernames, and secret API keys before sending prompts.
- 📋 **Editor Integration:** Grab highlighted code directly from your editor with one click and insert solutions straight back into your code.
- 🎯 **Flexible Prompt Modes:** Clean/Direct, Code-Only (no fluff/yap), Debug & Architect, or Custom Guardrails.

---

## 🚀 Getting Started

1. Make sure the Silknet local server is running (`npm start` or run `start-bridge.bat`).
2. Have the Silknet browser extension loaded in Chrome, Edge, or Brave.
3. Open any tab to **ChatGPT**, **Claude**, or **Gemini**.
4. Open the **Silknet** tab in your activity bar and start asking questions!

### Keyboard Shortcuts
- `Ctrl+Alt+A` (`Cmd+Alt+A` on Mac): **Ask Browser AI**
- `Ctrl+Alt+S` (`Cmd+Alt+S` on Mac): **Send Selected Code to Browser AI**
